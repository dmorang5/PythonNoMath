# Python para no matemáticos: De cero hasta reconocimiento facial

Este repositorio contiene las soluciones y ejemplos prácticos del curso de Udemy **"Python para no matemáticos: De cero hasta reconocimiento facial"** impartido por **Código 369**. Este curso está diseñado para enseñar Python a personas sin experiencia previa en matemáticas y abarca desde los conceptos básicos hasta técnicas avanzadas como el reconocimiento facial.

## Estructura del Repositorio

El repositorio contiene los ejercicios y proyectos realizados durante el curso, organizados en diferentes carpetas de acuerdo con los módulos y temas cubiertos. Algunos de los temas que puedes encontrar incluyen:

- Fundamentos de Python
- Manejo de datos con Python
- Introducción al uso de bibliotecas de Python
- Reconocimiento facial con OpenCV y otras herramientas

## Tecnologías Utilizadas

Las soluciones están implementadas principalmente en **Python**, y en algunos ejercicios se utilizan bibliotecas como **OpenCV** para procesamiento de imágenes y reconocimiento facial.

## Instrucciones de Uso

1. Clona el repositorio a tu máquina local:
    ```bash
    git clone https://github.com/dmorang5/PythonNoMath.git
    ```
2. Navega a la carpeta correspondiente al módulo que deseas explorar:
    ```bash
    cd PythonNoMath
    ```
3. Si es necesario, instala las dependencias para los proyectos:
    ```bash
    pip install -r requirements.txt
    ```
4. Ejecuta los scripts de Python en tu entorno local:
    ```bash
    python nombre_del_archivo.py
    ```
